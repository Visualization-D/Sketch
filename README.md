Creative Sketch Pro V8 — Release Notes
A complete, professional drawing studio in a single HTML file. No installation. No server. No accounts. 100% offline.
Created by Prof. Mohammad Lataifeh — College of Computing and Informatics, University of Sharjah
📧 lataifeh@gmail.com
⬇️ Download & Run
Download index.html and open it in any modern browser. That's it — your artwork never leaves your machine.
✨ What's New in V8

    🔤 Text Tool — click the canvas and just type. Live typing with a blinking caret, multiline support, sizes up to 400px, alignment and color controls, bold system font — built for titles, headlines, and large ads.
    👆 Brush-Aware Smudge — smudging now uses the active brush's shape, texture, and size, including free-form custom brush silhouettes.
    💧 Eyedropper — Alt + click picks any canvas color mid-stroke, or use the 💧 button. Picks exactly what you see, blends included.

Core Features

    🖌️ Painting engine — 30+ brushes (pencils 6B→technical, pen, marker, watercolor, oil, chalk, airbrush, FX set) with pressure sensitivity, grain/tooth, jitter, flow, and round/flat/square/custom tips
    🎨 Create your own brushes — sketch any mark on canvas and convert it; true free-form edges, automatic background removal, full transparency; image and experimental .abr import
    🗂️ Layers — unlimited layers with duplicate, reorder, opacity, and 16 blend modes
    🔧 Transform suite — Scale, Rotate, Skew, Perspective, and Mesh Distort with selectable density from 3×3 to 16×16
    ↔️ Move & edit — pick up and freely move any painted object, rectangular selections, Copy/Paste, Ctrl+D duplicate
    💾 Files — transparent PNG, layered PSD export (Photoshop/Procreate compatible) and PSD re-import to keep editing, ORA export — all with embedded authorship metadata
    ↩️ 200-step history with a save reminder at the limit
    🔒 Privacy by design — single file, fully offline, no telemetry
